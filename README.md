# LogTriage

**AI-powered log triage service.** Paste a log line, get back a severity classification and a suggested fix — powered by an LLM.

- **Live demo:** https://logtriage.onrender.com
- **Repo:** https://github.com/Saima-H/logtriage

> Note: hosted on Render's free tier. First request after inactivity may take ~20-30 seconds to wake.

---

## What it does

Given a log line like:
2026-10-01 10:23:11 ERROR disk usage 98% on web-server-3

LogTriage returns:

- **Severity:** `error` (one of: info, warn, error, critical)
- **Suggestion:** a one-line fix recommendation from the LLM

Every analysis is stored in the database, so you can browse past triage results from the web UI.

---

## Tech stack

- **Backend:** Python 3.13, FastAPI, SQLAlchemy, Pydantic
- **Database:** SQLite locally, PostgreSQL in production (via `DATABASE_URL`)
- **LLM:** Groq API (`openai/gpt-oss-20b`) with a graceful fallback if the API is unreachable
- **Frontend:** Vanilla HTML/CSS/JavaScript (no build step)
- **Testing:** pytest with FastAPI's `TestClient` + GitHub Actions CI
- **Deployment:** Render (free tier)

## API endpoints

| Method | Path | Description |
|--------|------|-------------|
| POST | `/analyze` | Analyze a log, store result, return it |
| GET | `/logs` | List recent logs (newest first) |
| GET | `/logs/{id}` | Fetch a single log by ID |
| GET | `/health` | Health check |

Interactive API docs available at `/docs` (auto-generated by FastAPI).
